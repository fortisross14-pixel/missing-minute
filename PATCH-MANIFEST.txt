MARA QUILBLE AND THE MISSING MINUTE
SCENES 01–02 + SCENE COMPOSER FOUNDATION PATCH
================================================
Patch version: 1.1.0
Base: src.zip supplied in the current conversation
Scope: changed and new files only; this is not the full project

WHAT THIS PATCH ADDS
--------------------
1. Playable schematic art for Scene 1: Department of Lost Causes.
2. Playable schematic art for Scene 2: Gannet’s End Harbor.
3. Lightweight SVG calibration assets for:
   - both room backgrounds
   - Mara, Pindle, Nib, Brine, Gus and the mechanical gull
   - all major scene props and state variants
   - inventory items
   - action buttons
4. A direct-manipulation Scene Composer:
   - drag scene visuals
   - resize with an on-scene handle
   - numeric X/Y/width/height/Z/opacity controls
   - actor start-position and scale editing
   - hotspot position, size and walk-point editing
   - optional linked hotspot movement
   - linked movement of state variants
   - camera pan controls for wide scenes
   - keyboard nudging
   - JSON import, export and clipboard copy
   - per-scene browser persistence
5. Scene-critical objects that were previously unreachable or absent from the rendered
   configuration are now represented, including the alarm handle, Gus, Captain Nib,
   Madame Brine and the harbor state variants.
6. Restart now clears only the game save and preserves Scene Composer work.
7. Automated scene validation tests.

STORY CONTENT
-------------
The existing Scene 1 and Scene 2 logic and dialogue files were preserved unchanged.
This patch supplies the schematic visuals, scene configuration and editor needed to use
that existing content.

HOW TO APPLY
------------
Extract this ZIP into the current project root and allow matching files to be replaced.
Do not delete the rest of the project.

Then run:

  npm install
  npm test
  npm run dev
